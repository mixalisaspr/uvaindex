紫外线指数等级详解——以及它遗漏了什么

紫外线指数（UV 指数）几乎是每个人都见过的那一条紫外线信息： 天气应用里一个按颜色区分、介于 0 到 11 之间的数字。它确实是 科学传播的一个优秀范例。但从设计上说，它也只衡量一件事—— 本文讨论的正是这句话的两个方面。

这个数字从何而来

UV 指数并不是对紫外线的测量。它衡量的是 紫外线使人体皮肤发红的能力， 这是另一种物理量。

阳光以光谱的形式到达地面——也就是能量在各个波长上的 分布。为了得出这个指数，要把这一光谱逐个波长乘以 CIE 红斑作用光谱：这是一条标准化曲线， 描述每个波长引起晒伤的效力。加权后的结果在整个 紫外波段积分，再乘以一个常数。[[cite:who_uvi_guide]]

UV 指数 = 红斑加权辐照度（W/m²）× 40
因此 UV 指数 1 = 0.025 W/m²；UV 指数 10 = 0.25 W/m²。

乘以 40 这个系数，纯粹是为了让地球上各种条件下的结果落在 一个好记的 0 到约 11 的范围内。它本身没有任何物理 意义——就像本站用除数 6 把 UVA 指数放到 可比的刻度上一样。

各个等级，以及世界卫生组织的建议

下列等级是世界卫生组织（WHO）、世界气象组织（WMO）和国际非电离辐射防护委员会（ICNIRP）的标准，基本上通行于 全世界。颜色也是标准的一部分，并非装饰。[[cite:who_uvi_guide]]

UV 指数等级颜色WHO 建议
0–2低绿色大多数人无需防护
3–5中等黄色正午前后寻找阴凉处；穿衬衫、涂防晒霜、戴帽子
6–7高橙色需要防护；减少正午时段的暴露
8–10很高红色加强防护；正午前后避免待在户外
11+极高紫色采取一切防护措施；未防护的皮肤几分钟内就可能晒伤

3 是关键的阈值。世界卫生组织从这个数值 开始建议采取防护，大多数国家的宣传活动也是围绕这个数字 开展的。低于 3 时，在正常的暴露时长下，大多数皮肤类型 不太可能出现红斑。

它实际能有多高？

这个刻度没有上限。11 是最高等级的起点， 而不是刻度的终点——应用以“11+”显示的方式 助长了这一常见误解。

利坎卡武尔的数值来自安第斯山一座高海拔火山上的剂量计测量，[[cite:cabrol2014]]其他紫外线研究人员认为这很可能是仪器误差，并提出了质疑，[[cite:mckenzie2015]]因此应把它视为已有说法的上限，而不是公认的纪录。极端数值来自所有放大因素同时叠加：头顶直射的太阳、 稀薄的臭氧柱、上方很少的大气、洁净干燥的空气，以及 来自下方的积雪反射。高海拔的 UVA 一文介绍了海拔梯度为什么因波长而异， 反射 UVA 一文则介绍了 反照率的贡献。

加权的作用——以及它隐藏了什么

下面是红斑加权在结构上带来的后果。这一作用 光谱随波长增加而下降得极其陡峭：与它在 UVB（中波紫外线）中的 峰值相比，它在 340 nm 处的效力要小约 一千倍。所以这个指数实际上是一台 UVB 测量仪。

在太阳正午时，到达地面的紫外线光子中约有 95% 是 UVA（长波紫外线）——但经过红斑加权后，UVA 只 贡献了 UV 指数的约 17%，其余约 83% 来自 UVB。这个指数由光谱中恰好会导致晒伤的那一小部分所主导。

对于它的本职工作——告诉你是否快要晒伤—— 这完全正确，无可指摘。问题在于， 这个数字随后被当成了通用的“今天紫外线有多少”的 信号，而它并不是。由于 UVB 和 UVA 对太阳角度、 臭氧、云和玻璃的反应截然不同，两者恰恰会在人们 不再留意的时候出现分歧：

  • 冬季。穿过大气的倾斜路径变长，意味着 挡在中间的臭氧多得多，这会剥离 UVB，而 UVA 大部分 保持不变。UV 指数大幅下降；UVA 只是小幅下降。参见 UVA 的季节变化。
  • 隔着玻璃。普通窗玻璃几乎会去除全部 UVB，所以室内的有效 UV 指数约为零——而 很大一部分 UVA 仍会透过。参见 玻璃能阻挡 UVA 吗。
  • 云层下。云对以 UVB 为主的 红斑波段的衰减大于对 UVA 的衰减，因此比例会再次改变。 参见阴天的 UVA。
  • 清晨和傍晚。与冬季同样的大气质量原理， 只是压缩到了几个小时内。参见 UVA 在什么时候最强。

在上述每一种情况下，较低的 UV 指数对晒伤风险的判断 都是真实的，却会让人对总体紫外线暴露产生误解—— 这正是本站要计算 单独的 UVA 指数的全部原因。

把两个指数结合起来看

最有用的习惯是把它们看作在回答两个不同的 问题，而不是在争夺同一个问题的答案。

问题要看的数字
我今天会晒伤吗？UV 指数
为了防晒伤，我现在需要防护吗？UV 指数 ≥ 3
我是否在累积导致光老化和色素沉着的剂量？UVA 指数
我的通勤或窗边的办公桌有影响吗？UVA 指数
我会合成维生素 D 吗？UV 指数（它反映 UVB 的多少）

最后一行值得多说几句，因为它最清楚地 说明了两者的分工：维生素 D 的合成由 UVB 驱动， 因此与 UV 指数密切相关，而 UVA 对此 毫无贡献——这一点在 UVA 与维生素 D 一文中有详细阐述。本站的计算器 之所以把实时 UV 指数与 UVA 指数并排显示，正是出于 这个原因：把它们放在一起看，差异就一目了然。
