    Who it's for

    UVA is the part of sunlight behind skin ageing, pigmentation and deep, cumulative damage — and the familiar UV Index barely registers it. A live UVA reading is useful wherever people plan time outdoors or care about their skin:

    • Travel blogs and destination guides — show readers what the sun is really like in the place you're writing about, today.
    • Dermatology, aesthetic and skincare clinics — give patients a daily reason to wear broad-spectrum sunscreen, especially on cloudy days when UVA still gets through.
    • Surf, kite and sailing schools — pick the Water or Sand surroundings so the reading includes reflected UVA.
    • Ski schools and mountain guides — snow reflects most UVA and it rises with altitude; choose Snow.
    • Pharmacies and sunscreen shops, hotels and beach clubs, schools, nurseries and sports clubs planning outdoor time.

    What the widget shows

    • The UVA Index right now on a 0–11+ scale with its band (Low to Extreme).
    • Today's peak and roughly when it happens, in the location's own time zone.
    • The hours to protect — when the UVA Index is Moderate (3) or higher.
    • A link to the full five-day forecast and model breakdown for that place.

    It runs exactly the same model as the UVA Index calculator: the sun's position, live cloud and aerosol data, altitude and the surroundings you pick. The method, its sources and its validation are written up in how the UVA Index is calculated.

    How to add it to your site

    Paste the code into any place that accepts raw HTML:

    • WordPress — add a Custom HTML block (or a Custom HTML widget in a sidebar).
    • Squarespace — add a Code block.
    • Wix — Add → Embed code → Embed HTML, then set the box to the widget's height.
    • Webflow — drop in an Embed element.
    • Shopify — a Custom Liquid section, or the HTML view of a page.
    • Ghost, Blogger, plain HTML — an HTML card or straight into your template.

    The widget stretches to the width of its container up to 340 px, and works down to about 240 px wide.

    Questions

    Does the widget set cookies or track my visitors?

    No. It sets no cookies and loads no analytics, so it doesn't add anything to your cookie banner. To compute the reading, the visitor's browser requests weather and aerosol data for your chosen location from the free Open-Meteo API, and may keep that response in its own storage for up to an hour so repeat page views don't fetch it again.

    Will it slow my page down?

    No. It's a small, lazy-loaded iframe with no framework and no web fonts: it only loads when a visitor scrolls near it, and it never blocks your own page from rendering.

    How often does it update?

    The reading is recomputed every five minutes from the sun's exact position; the cloud and aerosol data behind it refreshes every hour.

    Can I show more than one location?

    Yes — build one widget per place and paste each snippet where you want it. A travel guide can carry a different widget on every destination page.
