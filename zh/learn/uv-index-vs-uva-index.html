紫外线指数与 UVA 指数：两者各自衡量什么

紫外线指数（UV 指数）确实是一个有用的数字，但它回答的是一个特定的问题：这样的阳光会多快晒伤没有防护的皮肤？ 由于它是按晒伤加权的，所以它以 UVB（中波紫外线）为主，并系统性地低估了 UVA（长波紫外线）—— 尽管 UVA 占到达你身上的紫外线的绝大部分。

UV 指数究竟是什么

UV 指数（UVI）并不是对紫外线能量的直接测量。它是用红斑作用光谱加权后的地面紫外线光谱—— 红斑作用光谱是由 CIE 定义的一条曲线，描述每个波长使人体皮肤发红的效力。加权后的光谱经过积分和缩放（乘以 40 W/m⁻²）， 就得到了人们熟悉的 0–11+ 等级。[1]

这条红斑曲线的关键特点是，它向长波方向急剧下降。就晒伤而言，皮肤对 UVB 的敏感度远远高于 UVA—— 在某些波长上要高出约一千倍。

结果是：尽管在地面上 UVA 的原始能量远远超过 UVB，红斑加权却几乎把它抹掉了。 UV 指数实际上是一个主要反映 UVB 的数值——在太阳正午，UVI 以 UVB 为主，UVA 只贡献了一小部分。

UV 指数擅长什么

  • 它是衡量晒伤风险以及你多快会发红的绝佳参考。
  • 它能反映正午和夏季的峰值，此时引起晒伤的 UVB 最强。
  • 它是标准化的，国际公认，随处可查。

对于“为了避免晒伤，我现在该不该涂防晒霜？”这个问题，UVI 是合适的工具。

它反映不足的方面

UV 指数不能很好地代表 UVA 剂量，因此也不能很好地代表 UVA 造成的危害：

  • 光老化——胶原蛋白分解、皱纹和色素沉着主要是 UVA 的作用，UVI 几乎反映不出来。
  • 真皮深层损伤和间接 DNA 损伤，以及 UVA 对黑色素瘤的作用。
  • 透过玻璃的照射——在车里或窗边，你几乎接受不到 UVB（所以“有效”UVI 很低），却会接受大量 UVA。
  • 阴天和非高峰时段——当 UVI 已经下降时，UVA 仍保持在相对较高的水平，因为 UVA 随太阳角度和云层的变化要小得多。
  • 光敏反应，其中许多是由 UVA 驱动的。

为什么 UV 指数低仍可能意味着 UVA 很高

想象一下傍晚，或者一个雾蒙蒙/阴沉的日子，或者坐在阳光充足的窗边。UV 指数可能显示为低到中等， 因为引起晒伤的 UVB 已经减弱。但 UVA——在一天中更稳定，能透过窗户玻璃，被云层削弱的程度也远小于你能感觉到的那部分光—— 仍可能向你皮肤的深层输送可观的剂量。UVI 给你一个令人安心的数字，而 UVA 照射却在悄然继续。

为什么需要专门的 UVA 指数

一个专门针对 UVA 的量度可以填补这一空白。它不使用红斑加权，而是关注未加权的 UVA 波段（≈315–400 nm）—— 即到达地面的实际长波辐照度，以 W/m² 计。它告诉你的是导致老化和深层长期损伤的那部分照射，而这是 UV 指数在设计上无法传达的。

本站存在的原因：没有哪个主流的免费天气 API 提供纯 UVA 数据——它们发布的都是按红斑加权的 UV 指数。 所以本站根据太阳几何位置加上实时大气数据（云量、气溶胶、海拔、地表反射率）推算 UVA， 提供 UV 指数所无法提供的专门 UVA 读数。关于估算的具体构建方式，请参见 UVA 指数是如何计算的。

UVA 指数等级

原始的 UVA 辐照度（以 W/m² 计）虽然精确，却不为人熟悉，所以我们把它换算成和 UV 指数一样的 0–11+ 等级。 换算只用一个常数：UVA 指数 = UVA 辐照度 ÷ 6。选择这个除数，是为了让太阳位于头顶、晴空条件下的辐照度 （在我们的模型中约为 64–66 W/m²）读数约为 11——给人与热带地区峰值 UV 指数相同的“满刻度”感觉。 各档沿用世界卫生组织（WHO）UV 指数的颜色和用语，所以你已经熟悉的数字可以直接套用：

UVA 指数等级≈ 辐照度
低于 3低低于 18 W/m²
3 至不足 6中等18 至不足 36 W/m²
6 至不足 8高36 至不足 48 W/m²
8 至不足 11很高48 至不足 66 W/m²
11 及以上极高66 W/m² 及以上

由于指数与辐照度严格成正比，两个数字说明的是同一件事——指数只是一种更便于一眼看懂的读法。

两者结合使用

这并不是说“UV 指数不好，UVA 指数好”。两者回答的是不同的问题，相辅相成：

  • UV 指数 → 短期晒伤风险（主要是 UVB）。
  • UVA 指数 → 导致老化和深层累积性损伤的长波 UVA 剂量。

同时查看两者，比只看其中任何一个数字，都能更全面地了解太阳对你皮肤的影响。
