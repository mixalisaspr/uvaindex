关于本站

uvaindex.org 的宗旨，是让 UVA 辐射拥有一个属于自己的数值。人们熟悉的紫外线指数（UV 指数）确实很有用，但它只回答一个问题——太阳多快会把我的皮肤晒伤？——因此它几乎忽略了 UVA，而 UVA 正是阳光中对皮肤老化以及深层、累积性损伤负有最主要责任的部分。本站用一个专门的、简单易懂的 UVA 指数来填补这一空白。

为什么需要 UVA 指数？

标准的 UV 指数是按红斑效应加权的——针对晒伤而设计——因此以 UVB 为主导。UVA 几乎不会让它发生变化，尽管实际到达你身上的紫外线中，UVA 占绝大多数，在一天中更长的时间里保持较高水平，能够穿透云层和玻璃，并导致光老化和间接的 DNA 损伤。所以，即使 UV 指数很低、让人感觉舒适，你仍可能接受了相当大的 UVA 剂量。

专门针对 UVA 的指标能让这种看不见的暴露变得可见。它关注的是未加权的 UVA 波段（≈315–400 nm）——即真正照射到地表的长波辐照度——并把它放到你在 UV 指数上早已熟悉的、直观的 0–11+ 等级上。完整的论证请见为什么 UV 指数还不够。

简而言之：UV 指数告诉你今天会不会晒伤；UVA 指数告诉你的是皮肤老化，以及 UV 指数从未打算反映的那种缓慢而更深层的损伤。

这不是官方指数

我们希望开诚布公地说明：目前并不存在官方的 UVA 指数。UV 指数是由世界卫生组织（WHO）、世界气象组织（WMO）等机构制定的国际标准。UVA 没有对应的标准——没有任何机构发布 UVA 指数，也没有任何免费的天气 API 提供纯 UVA 数据。

因此，这里的一切都是估算值：

  • UVA 辐照度是由物理模型推算得出的，而不是由仪器测量的。我们计算太阳位置，并根据海拔、气溶胶、云量和地面反射率进行实时修正。完整方法请见UVA 指数是如何计算的。
  • 0–11+ 的等级和颜色分级是我们自己出于实用考虑做出的选择。我们沿用了世界卫生组织的 UV 指数分级，让这个数字显得熟悉，但它们并不是官方的 UVA 标准。
  • 这些数值最好被视为相对参考——非常适合比较不同时间、地点和条件——而不是仪器级的绝对读数。

为什么我们仍然要做

因为这一空白真实存在，而提高认识很重要。人们自然会以为 UV 指数低就意味着“太阳现在伤不到我”，但对于皮肤老化和长期的 UVA 损伤来说，这根本不成立。一个透明、免费、无需登录的估算——展示每一项输入和每一步计算——总比完全没有 UVA 信息更有用。我们宁愿提供一个诚实、标注清楚的近似值，也不愿让 UVA 继续处于不可见的状态。

透明正是关键所在：计算器为每一次读数展示输入参数和模型分解，计算方法用通俗的语言写明，源代码也是公开的，任何人都可以查看或改进。

参考来源与编辑标准

一个非官方指数的可信度，完全取决于其背后的证据，因此知识库会注明参考来源。有关健康和物理的论述都链接到每篇文章末尾的编号参考文献——主要是经同行评审的研究，以及世界卫生组织、国际癌症研究机构、美国 FDA 和欧盟委员会等机构发布的指导意见。

  • 优先引用原始来源。我们引用原始的试验、测量或法规，而不是新闻摘要；如果某项发现存在争议、仅来自单项研究，或是在细胞而非人体上得出的，我们也会明确说明。
  • 模型数值会标明为模型数值。用本站自有模型计算出的数字会如实注明，并且该模型会与独立数据进行对照检验——计算方法页面介绍了具体方法、所依据的已发表算法以及验证结果。
  • 每篇文章都注明审核日期，完整的编辑历史公开在GitHub 上。
  • 欢迎指正。如果某项论述有误、已经过时，或有其他来源能提供更好的支持，请提交 issue，我们会进行修正。

如何负责任地使用

  • 请将它与官方 UV 指数配合使用，而不是替代后者——两者回答的是不同的问题。
  • 请把各个等级视为参考，而不是精确的阈值。
  • 涉及医疗或皮肤健康方面的决定，请咨询合格的专业人士。本站仅供科普参考，不构成医疗建议。

本站是如何构建的

这是一个小巧、快速、没有任何依赖的网站，完全在你的浏览器中运行。大气数据来自免费的Open-Meteo API（无需密钥，没有跟踪），太阳相关的计算在本地运行，而且整个网站加载后即可离线使用。它免费且开源。

网站所有者还可以通过免费的 UVA 指数小组件在自己的页面上显示实时读数——只需复制粘贴一次，无需密钥，也没有 Cookie。

开源

整个项目都是开源的，并以宽松的 MIT 许可证发布。完整的源代码——包括计算器、物理模型以及知识库的每一个字——都托管在GitHub 上。你可以在那里准确查看每个读数是如何得出的，提交issue，或者发起 pull request 来改进它。我们选择开源，是因为一个非官方指数的可信度完全建立在透明之上：如果没有任何机构为这个数字背书，你至少应该能够自己检查和质疑其中的计算。

想要帮忙？我们欢迎模型改进、内容勘误、无障碍修复和错误报告——请参阅贡献指南开始参与。

隐私

本站没有账户。以下信息会离开你的浏览器：

  • 你的位置，用于获取预报。你搜索的地点的坐标，或在你允许的情况下你设备的位置，会被发送到Open-Meteo 以获取天气和空气质量数据。如果你使用设备位置，坐标还会被发送到BigDataCloud，用于查询最近城镇的名称。我们不会在任何地方存储这些坐标。
  • 经你同意后的统计分析。我们使用 Google Analytics 统计访问量，并了解哪些页面有用。来自欧盟/欧洲经济区、英国和瑞士的访客会先被征求同意，除非他们接受，否则不会加载任何内容；在其他地区则默认开启。无论哪种情况，你都可以随时通过（每个页面的页脚中也有）更改你的选择。你的选择会保存在浏览器的本地存储中。
