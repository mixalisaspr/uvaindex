UVAナレッジベース

紫外線A波（UVA）についての短くわかりやすいガイド集です。UVAとは何か、UVBとどう違うのか、 肌にとってなぜ重要なのか、そしておなじみのUVインデックスだけでは なぜ全体像がわからないのかを解説します。

  • UVA（紫外線A波）とは何か

    UVAは紫外線のうち波長の長い波長帯（315–400 nm）です。紫外線のスペクトルの中でどこに位置するのか、地上に届く紫外線の約95%がUVAである理由、そして1日の中で、雲を通して、ガラス越しにどう振る舞うのかを解説します。

    読む →

  • UVAとUVBの違いとは？

    UVAとUVBを比較します。波長、肌のどこまで届くか、日焼け（サンバーン）と光老化、ビタミンD、皮膚がんでの役割、そして雲・ガラス・時間帯・季節がそれぞれにどう影響するかを解説します。

    読む →

  • UVインデックスとUVA指数：それぞれが測っているもの

    UVインデックスは紅斑で重み付けされているため、UVBが大部分を占め、UVAはほとんど反映されません。それぞれの指数が測っているもの、UVインデックスが低くてもUVAが高い状況、そして0〜11+のUVA指数の読み方を解説します。

    読む →

  • UVインデックスのスケールを解説 — そしてそこに含まれていないもの

    UVインデックスの数値の意味、0〜11+のスケールの由来、WHOの区分の色と推奨される対策、実際にどこまで高くなるのか、そしてUVAを過小に示す原因となっている紅斑作用の重み付けを解説します。

    読む →

  • UVA指数はどのように計算されるのか

    UVA指数の計算方法をすべて公開します。地表のUVA放射照度（315–400 nm、W/m²）を放射伝達ルックアップテーブルとリアルタイムの雲・かすみ・気圧・積雪データから求める方法、正確な計算式と前提条件、検証方法、そして考慮していない要因を解説します。

    読む →

  • UVA（紫外線A波）の危険性

    UVAが健康に与える影響：光老化としわ、活性酸素種を介した間接的なDNA損傷、皮膚がんとメラノーマのリスク、目の損傷、免疫抑制、光線過敏症。さらに、曝露を減らすための実践的な方法も紹介します。

    読む →

  • UVAが最も強いのは何時？1日の変化のカーブ

    UVAのピークは南中時刻（太陽正午）ですが、そのカーブはUVインデックスよりずっとなだらかなため、朝や夕方には相対的にずっと多くのUVAが含まれます。1時間ごとの数値、影のルールが通用しない理由、そして南中時刻がめったに12:00にならない理由を解説します。

    読む →

  • 曇りの日のUVA：どれだけ届くのか

    雲は日差しの明るさほどにはUVAを弱めません。そして切れ切れの雲は、一時的にUVAを快晴時以上に押し上げることもあります。雲の種類ごとの透過率、雲の下でのUVAとUVBの比較、雲による増強効果、そしてUVA指数での扱い方を解説します。

    読む →

  • UVAがUVBほど季節によって変わらない理由

    オゾンはUVBを強く吸収しますが、UVAはほとんど吸収しません。そのため、冬の低い太陽ではUVBが激減する一方、UVAはわずかしか減りません。冬や早朝の紫外線でUVAの割合が不釣り合いに高い理由を数値とともに解説し、UVインデックスが低くてもUVAが低いとは限らない理由を説明します。

    読む →

  • 世界のUVA：緯度の影響は思っているほど大きくない理由

    オゾンはUVAをほとんど吸収しないため、赤道から極に向かうUVAの減り方はUVインデックスよりずっと緩やかです。世界の都市の快晴時のピークUVA指数、南半球のほうが紫外線が強い理由、そして地域差を実際に生んでいる要因を解説します。

    読む →

  • 標高とUVA：山、登山、そして飛行機

    紫外線は標高とともに強くなりますが、UVAの増え方は、よく引用される「1000 mごとに10%」よりも緩やかです。この数値は紅斑紫外線のものだからです。標高による増加率が波長によって異なる理由、雪と澄んだ空気がそれをさらに強める仕組み、そして操縦室のUVAとパイロットのメラノーマに関する研究が示すことを解説します。

    読む →

  • 照り返しのUVA：雪、砂、水面、コンクリート

    地面からの照り返しは、浴びるUVAをさらに増やします。そして紫外線の反射率は、目に見える明るさとは別物です。地表ごとの反射率、スキーヤーやボートに乗る人があごの下を日焼けする理由、砂浜で日陰が役に立たない理由、UVA指数が地表の反射率をどうモデル化しているかを解説します。

    読む →

  • ガラスはUVAを防ぐのか：窓、車、UVカットフィルム

    普通の窓ガラスはUVBをほぼすべて遮りますが、UVAはかなりの割合を通します。住宅・オフィス・車のガラスをどれだけ通るのか、フロントガラスとサイドガラスの違い、運転者の皮膚がん研究が示すこと、UVカットフィルムの選び方を解説します。

    読む →

  • 服はUVAを防ぐのか：UPF表示と本当に効果のある対策

    UPFは紅斑で重み付けされているため、SPFと同じく実質的にはUVBの指標です。だからこそ欧州の規格には別途UVAの上限が設けられています。素材・色・織り方による生地の透過率、濡れたり伸びたりしたときの変化、そして帽子や日陰の実際の効果を解説します。

    読む →

  • 日焼け止めのUVA表示を読み解く：PA+++、丸囲みのUVAマーク、星の数、臨界波長

    SPFはほぼUVBだけを測る指標です。EUの丸囲みUVAマーク、日本のPA表示、Bootsの星評価、米国のブロードスペクトル試験、アボベンゾンの光安定性、そして地域ごとに使えるUVAフィルターから、本当のUVA防御力を読み取る方法を解説します。

    読む →

  • 日焼け止めは本当はどれだけ必要か：そしてなぜUVAが最も損をするのか

    日焼け止めは2 mg/cm²で試験されますが、実際にはその4分の1しか塗られておらず、防御力は塗る厚さに対して指数関数的に低下します。塗る量の不足と光分解がUVA防御力に最も大きく響く理由と、小さじルール・2本指ルールを解説します。

    読む →

  • UVAと目：サングラス、UV400、白内障、翼状片

    UVAがどのように目に届き、目を傷つけるのか。UV400、EN ISO 12312-1、ANSI Z80.3が実際に何を保証しているのか、紫外線カットのない濃い色のレンズがかけないより悪いかもしれない理由、そしてレンズの濃さよりフレームの形が重要な理由を解説します。

    読む →

  • UVAと肌の老化：光老化は実際にどう起こるのか

    UVAは真皮まで届き、コラーゲンを分解する酵素を働かせます。光子からしわができるまでの仕組み、毎日の日焼け止めで測定可能な老化が止まることを示した試験、トラック運転手や双子から得られた証拠、そして本当にダメージを修復できる方法を解説します。

    読む →

  • UVAで肌は黒くなる？サンタン、サンバーン、ベースタンの誤解

    UVAは、もともとあるメラニンを酸化させることで数分のうちに肌を黒くします。しかしその日焼けには、ほとんど防御効果がありません。3つの異なる日焼け反応、UVAではほとんど赤くならない理由、そしてそれが日焼けマシンやベースタンの考え方にとって何を意味するのかを解説します。

    読む →

  • UVAとビタミンD：代償だけで、恩恵はゼロ

    ビタミンDの合成を引き起こすのは295–300 nm付近のごく狭いUVBで、315 nm未満で完全に止まります。UVAはビタミンDをまったくつくりません。そのため、冬の日差し、窓越しの光、日焼けマシンは、見返りのない曝露にすぎません。

    読む →

  • UVA、メラニンと色素沈着：肝斑、色素沈着、肌の色

    肝斑や炎症後色素沈着を引き起こすのは、UVBよりもはるかにUVAと可視光です。だからこそ、酸化鉄を含む色付きの日焼け止めが透明なものより効果的なのです。メラニンが何を防ぎ、何を防がないのかを、フィッツパトリックのスキンタイプ別に解説します。

    読む →

  • 光線過敏症：UVAを危険にする薬と病気

    薬による光線過敏症のほとんどはUVAが原因で、だから車やオフィスの窓越しでも、曇りの日でも起こります。光毒性反応と光アレルギー性反応の違い、主な薬の種類、多形日光疹・ループス・ポルフィリン症、そして本当に効果のある対策を解説します。

    読む →

  • 屋内のUVA：ネイルライト、日焼けマシン、そして照明が実際に出しているもの

    ジェルネイル用ライトはほぼ純粋なUVA、日焼けマシンはUVAに大きく偏ったスペクトルを出し、画面は紫外線をまったく出しません。屋内の各光源が実際に何を出しているのか、正午の太陽とW/m²で比べるとどうか、本当のリスクはどこにあるのかを解説します。

    読む →

  • UVAを自分で測るには：測定器、カード、スマホにまつわる誤解

    UVAを実際に測定するには何が必要なのか。分光放射計、広帯域放射計、安価な一般向け測定器、フォトクロミックカードのそれぞれの弱点と、スマートフォンではまず紫外線を測れない理由、そして測定値が妥当かどうかを確かめる方法を解説します。

    読む →

  • ミネラルとケミカルの日焼け止め：UVA対策に優れているのはどちら？

    酸化亜鉛、酸化チタン、有機系紫外線フィルターを、UVAのカバー範囲、光安定性、白浮き、敏感肌、サンゴ礁保護の規制、体内への吸収の観点で比較。「ミネラルは反射し、ケミカルは吸収する」という説がほぼ誤りである理由と、選び方を解説します。

    読む →

  • 水はUVAを防ぐのか：水泳、シュノーケリング、日焼け止め

    水は紫外線をあまり防ぎません。澄んだ水ではUVAはUVBよりはるかに深くまで届き、水深50センチでもかなりの紫外線を浴び、濡れた肌からは日焼け止めがすぐに落ちてしまいます。プール、海、湖で何が起きているのか、そして「耐水性」が本当に意味することを解説します。

    読む →

  • 赤ちゃんと子どもの紫外線対策

    子どもの肌と目が紫外線に弱い理由、赤ちゃんはいつから日焼け止めを使えるのか、子ども用の日焼け止めの選び方、そしてより重要な日陰・衣服・帽子・サングラスの習慣を解説します。「生涯の紫外線の80%は18歳までに浴びる」という俗説についても。

    読む →

  • UVAは髪を傷めるのか：髪の色、タンパク質、そして頭皮

    日光は2つの形で髪を傷めます。UVAはメラニンや染料を分解して髪の色を退色させ、明るくします。UVBは髪の毛のタンパク質を劣化させます。ブロンド、白髪、染めた髪が最も影響を受ける理由、髪が頭皮をどれだけ守るのか、そして本当に役立つ対策を解説します。

    読む →

  • 日焼け止めは毎日必要なのか

    毎日日焼け止めを塗る価値があるかどうかは、天気やUVインデックスだけでなく、実際にどれだけのUVAを浴びるかで決まります。曇りの日、冬、窓際での仕事、運転、画面、肌の色の濃い人など、状況別のガイドと、毎日の日焼け止めに関する臨床試験の証拠を紹介します。

    読む →
