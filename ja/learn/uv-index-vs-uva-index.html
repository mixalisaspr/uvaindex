UVインデックスとUVA指数：それぞれが測っているもの

UVインデックスは本当に役に立つ数値ですが、答えているのは1つの特定の問い、つまり この日光は、何も対策していない肌をどれだけ速く日焼け（サンバーン）させるかです。日焼けで 重み付けされているため、UVB（紫外線B波）が大部分を占め、UVA（紫外線A波）を系統的に軽く扱っています。 UVAこそが、あなたに届く紫外線の大部分を占めているにも かかわらずです。

UVインデックスとは実際には何か

UVインデックス（UVI）は、紫外線のエネルギーをそのまま測った値ではありません。地表の紫外線スペクトルを 紅斑作用スペクトルで重み付けしたものです。これはCIEが定めた曲線で、各波長が人の肌を 赤くするのにどれだけ効果的かを表しています。重み付けしたスペクトルを積分し、スケーリング（40 W/m⁻²を 掛ける）して、おなじみの0〜11+の尺度にしています[1]。

この紅斑の曲線の重要な特徴は、長い波長に向かって急激に下がることです。日焼け（サンバーン）に関して言えば、 肌はUVAよりUVBに対してはるかに敏感です。一部の波長では、1,000倍程度も敏感です。

その結果：地表でのエネルギーそのもので見ればUVAはUVBよりはるかに多いのに、紅斑の 重み付けによってUVAはほとんど消されてしまいます。UVインデックスは事実上ほとんどUVBの数値 なのです。南中時刻（太陽正午）のUVIはUVBが大部分を占め、UVAの寄与はわずかな部分にすぎません。

UVインデックスが得意なこと

  • 日焼け（サンバーン）のリスクと、どれだけ速く赤くなるかを知るための優れた目安です。
  • 日焼けを起こすUVBが最も強い真昼と夏のピークをとらえます。
  • 標準化されており、国際的に認められ、どこでも手に入ります。

「日焼けしないように、今すぐ日焼け止めを塗るべきか？」という問いには、UVIが適した道具です。

十分に表せていないもの

UVインデックスはUVAの線量の代わりとしてはあまり当てにならず、したがってUVAが引き起こす害の目安としても当てになりません。

  • 光老化：コラーゲンの分解、しわ、色素沈着は主にUVAによる影響で、UVIにはほとんど反映されません。
  • 真皮深部へのダメージと間接的なDNA損傷、そしてメラノーマへのUVAの寄与。
  • ガラス越しの曝露：車の中や窓辺では、UVBはほとんど受けません（そのため「実質的な」UVIは低くなります）が、UVAはたっぷり受けます。
  • 曇りの日やピーク以外の時間帯：UVAは太陽の角度や雲による変化がはるかに小さいため、UVIが下がっても比較的高いままです。
  • 光線過敏反応：その多くはUVAによって引き起こされます。

UVインデックスが低くてもUVAが高いことがある理由

夕方や、かすんだ日・曇りの日、あるいは日の当たる窓辺に座っているところを思い浮かべてください。日焼けを 起こすUVBが弱まっているため、UVインデックスは「弱い」から「中程度」を示すかもしれません。しかしUVAは、 1日を通じてより安定しており、窓ガラスを通り抜け、肌で感じる光よりも雲で弱められにくいため、肌の深い層に まだかなりの線量を届けていることがあります。UVIは安心させる数値を示しますが、その間もUVAの曝露は静かに 続いているのです。

UVA専用の指数が必要な理由

UVAに特化した指標が、このすき間を埋めます。紅斑による重み付けの代わりに、 重み付けなしのUVAの波長域（約315–400 nm）、つまり地表に届く長波長の実際の 放射照度をW/m²で見るのです。これによって、老化や、深部の長期的なダメージの原因となる曝露がわかります。 UVインデックスはそれを伝えるようには作られていません。

このサイトがある理由：一般的な無料の気象APIで、純粋なUVAを提供しているものはありません。 どれも紅斑で重み付けされたUVインデックスを公開しています。そこでこのサイトでは、太陽の幾何学的な位置と リアルタイムの大気データ（雲、エアロゾル、標高、地表の反射率）からUVAを導き出し、 UVインデックスでは得られないUVA専用の値を示しています。推定値がどのように作られているかは、 UVA指数の計算方法で詳しく説明しています。

UVA指数の尺度

UVA放射照度そのもの（W/m²）は正確ですがなじみがないため、UVインデックスと同じように0〜11+の尺度に 置き換えています。換算に使うのは1つの定数だけです。UVA指数 = UVA放射照度 ÷ 6。この 割る数は、快晴時の真上の太陽（このモデルでは約64–66 W/m²）がおよそ11になるように 選ばれており、熱帯でのUVインデックスのピークと同じ、尺度の上限の感覚が得られます。レベルの区分には WHOのUVインデックスの色と表現をそのまま使っているので、すでに理解している数値の感覚がそのまま通用します。

UVA指数レベル放射照度（目安）
3未満弱い18 W/m²未満
3以上6未満中程度18以上36 W/m²未満
6以上8未満強い36以上48 W/m²未満
8以上11未満非常に強い48以上66 W/m²未満
11以上極端に強い66 W/m²以上

指数は放射照度に厳密に比例しているので、どちらの数値も同じことを伝えています。指数のほうが、 ひと目で読み取りやすいというだけです。

両方を合わせて使う

これは「UVインデックスは悪く、UVA指数は良い」という話ではありません。両者は異なる問いに答えており、 互いを補い合っています。

  • UVインデックス → 短期的な日焼け（サンバーン）のリスク（主にUVB）。
  • UVA指数 → 老化や深部の累積的なダメージを引き起こす長波長のUVAの線量。

両方を確認すれば、どちらか一方の数値だけよりも、太陽があなたの肌に何をしているのかをより完全に把握できます。
