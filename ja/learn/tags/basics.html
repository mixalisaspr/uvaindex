基礎知識

基礎知識のタグが付いたナレッジベースの記事です。

  • UVA（紫外線A波）とは何か

    UVAは紫外線のうち波長の長い波長帯（315–400 nm）です。紫外線のスペクトルの中でどこに位置するのか、地上に届く紫外線の約95%がUVAである理由、そして1日の中で、雲を通して、ガラス越しにどう振る舞うのかを解説します。

    読む →

  • UVAとUVBの違いとは？

    UVAとUVBを比較します。波長、肌のどこまで届くか、日焼け（サンバーン）と光老化、ビタミンD、皮膚がんでの役割、そして雲・ガラス・時間帯・季節がそれぞれにどう影響するかを解説します。

    読む →

  • UVインデックスのスケールを解説 — そしてそこに含まれていないもの

    UVインデックスの数値の意味、0〜11+のスケールの由来、WHOの区分の色と推奨される対策、実際にどこまで高くなるのか、そしてUVAを過小に示す原因となっている紅斑作用の重み付けを解説します。

    読む →

  • UVAが最も強いのは何時？1日の変化のカーブ

    UVAのピークは南中時刻（太陽正午）ですが、そのカーブはUVインデックスよりずっとなだらかなため、朝や夕方には相対的にずっと多くのUVAが含まれます。1時間ごとの数値、影のルールが通用しない理由、そして南中時刻がめったに12:00にならない理由を解説します。

    読む →

  • 曇りの日のUVA：どれだけ届くのか

    雲は日差しの明るさほどにはUVAを弱めません。そして切れ切れの雲は、一時的にUVAを快晴時以上に押し上げることもあります。雲の種類ごとの透過率、雲の下でのUVAとUVBの比較、雲による増強効果、そしてUVA指数での扱い方を解説します。

    読む →

  • ガラスはUVAを防ぐのか：窓、車、UVカットフィルム

    普通の窓ガラスはUVBをほぼすべて遮りますが、UVAはかなりの割合を通します。住宅・オフィス・車のガラスをどれだけ通るのか、フロントガラスとサイドガラスの違い、運転者の皮膚がん研究が示すこと、UVカットフィルムの選び方を解説します。

    読む →

  • 服はUVAを防ぐのか：UPF表示と本当に効果のある対策

    UPFは紅斑で重み付けされているため、SPFと同じく実質的にはUVBの指標です。だからこそ欧州の規格には別途UVAの上限が設けられています。素材・色・織り方による生地の透過率、濡れたり伸びたりしたときの変化、そして帽子や日陰の実際の効果を解説します。

    読む →

  • UVAで肌は黒くなる？サンタン、サンバーン、ベースタンの誤解

    UVAは、もともとあるメラニンを酸化させることで数分のうちに肌を黒くします。しかしその日焼けには、ほとんど防御効果がありません。3つの異なる日焼け反応、UVAではほとんど赤くならない理由、そしてそれが日焼けマシンやベースタンの考え方にとって何を意味するのかを解説します。

    読む →

  • 日焼け止めは毎日必要なのか

    毎日日焼け止めを塗る価値があるかどうかは、天気やUVインデックスだけでなく、実際にどれだけのUVAを浴びるかで決まります。曇りの日、冬、窓際での仕事、運転、画面、肌の色の濃い人など、状況別のガイドと、毎日の日焼け止めに関する臨床試験の証拠を紹介します。

    読む →
